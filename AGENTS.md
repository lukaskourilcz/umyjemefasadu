# Agent guide

Řiďte se kořenovým `CLAUDE.md` a `docs/DESIGN_SYSTEM.md`. Platí pro všechny
agenty a nástroje bez ohledu na jejich vlastní název. Před úpravou čtěte
`NEEDED.md`; neověřený obchodní údaj ani placeholder nesmí být publikován jako
skutečnost. Specifická pravidla jsou v `src/CLAUDE.md`, `src/admin/CLAUDE.md`
a `api/CLAUDE.md`.
